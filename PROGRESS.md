## Hero стал полноценным слайдером 29.09.2026
- Было: три направления переключались только вкладками и автосменой, слайды растворялись друг в друга.
- Стало: слайды **разъезжаются по горизонтали** (уходящий уезжает в одну сторону, входящий приходит с другой), добавлены **стрелки, точки-индикаторы и свайп**. Вкладки с названиями направлений оставлены — по ним видно, что за слайд.
- **Две правки 29.09 по жалобе клиента («свайп не работает, первый слайд сам не переключается»):**
  - Автопрокрутка вставала на паузу по `mouseenter` на hero, а hero занимает весь экран — курсор почти всегда над ним, поэтому слайды стояли. Пауза по наведению убрана: теперь автосмена замирает только в фоновой вкладке и пока фокус клавиатуры внутри слайда.
  - Свайп был на `touchstart`/`touchend`: браузер принимал жест за прокрутку и отменял цепочку, `touchend` не приходил. Переведён на pointer-события плюс `touch-action: pan-y` у `.hero` — вертикальную прокрутку браузер забирает себе, горизонталь отдаёт слайдеру. Мышь из свайпа исключена, иначе протяжка для выделения текста листала бы слайд.
- Управление: **стрелки и точки по просьбе клиента убраны** — переключение автоматическое, каждые 3,5 с (правка клиента 29.09, было 7 с). Вручную можно переключить вкладкой с названием направления, свайпом пальцем (только явно горизонтальный жест, вертикальная прокрутка не перехватывается) или стрелками клавиатуры при фокусе на вкладках. Автосмена останавливается при наведении и фокусе, после ручного переключения таймер стартует заново.
- Технически: панели лежат друг на друге в одной ячейке грида (`.hero-panes { display: grid }`, `.hero-pane { grid-area: 1/1; align-self: end }`) — высота блока равна самому высокому слайду, контент не прыгает. Переход — inline-стили transform/opacity с принудительным reflow перед стартом. Неактивные слайды получают `inert`, чтобы их ссылки не ловили фокус с клавиатуры.
- Стрелки и точки-кнопки были сделаны, затем удалены (правка клиента 29.09).
- Вместо них — **индикатор статуса**: три полоски под слайдом, активная заполняется за 3,5 секунды и показывает отсчёт до автопрокрутки, пройденные залиты целиком. Полоски не кликабельные, только индикация. Заполнение сделано через `scaleX` (считает видеокарта), а не через `width` — иначе полоска росла рывками; пройденные доливаются плавным переходом. При наведении на hero заливка замирает вместе с автосменой (`animation-play-state: paused`), при `prefers-reduced-motion` анимации нет — полоска просто залита.
